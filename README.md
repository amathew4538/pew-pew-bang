# Pew Pew Bang

A lighthearted Boomer Shooter with multiplayer!

## Building this game

To build this game, you must have an FMod Account

1. `git clone https://github.com/amathew4538/pew-pew-bang`
2. Open the repo in Godot
3. Install Epic Online Services Godot, FMod by Utopia, and GodotSteam
4. Export the game!
